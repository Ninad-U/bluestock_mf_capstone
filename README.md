# Bluestock Mutual Fund Analytics

## Project Overview

Bluestock Mutual Fund Analytics is an end-to-end data analytics project focused on mutual fund performance, investor behavior, risk analysis, and industry trends.

The project uses Python, Pandas, SQLite, SQL, and Power BI to clean, validate, analyze, and visualize mutual fund data.

### Key Areas

- Industry trends: AUM, SIP inflows, and folio growth
- Fund performance and benchmark comparison
- Risk metrics: Sharpe, Sortino, Alpha, Beta, and Maximum Drawdown
- Investor and SIP behavior
- Advanced analytics: VaR, CVaR, investor cohorts, SIP continuity, and portfolio concentration
- Interactive Power BI dashboards

## Data

The project processes 10 mutual fund datasets covering:

- Fund master information
- Historical NAV
- Fund performance
- Investor transactions
- Portfolio holdings
- Fund-house AUM
- SIP inflows
- Benchmark indices
- Category inflows
- Industry folio counts

The raw datasets are stored in `data/raw/`.
Cleaned datasets are generated in `data/processed/`.

## ETL Pipeline

The ETL workflow is:

```text
Raw CSV Files
      ↓
Extract & Standardise
      ↓
Transform & Validate
      ↓
Load to SQLite
      ↓
Processed CSV + SQLite Database
      ↓
Power BI Dashboard
```

The pipeline performs:

- Date and column standardisation
- Numeric type conversion
- Duplicate removal
- Dataset-specific validation
- Investor transaction validation
- AMFI code cross-validation
- Generation of cleaned CSV files

## Setup

### Requirements

- Python 3.8+
- Pandas
- NumPy
- SQLAlchemy
- Matplotlib
- Seaborn
- Plotly
- SciPy
- Jupyter
- Power BI Desktop

### Install Dependencies

From the project root:

```bash
pip install -r requirements.txt
```

### Run the ETL Pipeline

From the project root:

```bash
python scripts/run_pipeline.py
```

This runs the ETL workflow and generates the cleaned CSV files in `data/processed/`.
The ETL pipeline also loads the cleaned datasets into the SQLite database:

```text
data/db/bluestock_mf.db
```

### Run Analytics

Performance metrics can be calculated using:

```bash
python scripts/compute_metrics.py
```

The resulting analytics files are saved in:

```text
data/analytics/
```

The Jupyter notebooks in `notebooks/` contain the EDA, performance analysis, and advanced analytics workflows.

### Open the Power BI Dashboard

1. Open Power BI Desktop.
2. Open:
   ```text
   dashboard/bluestock_mf.pbix
   ```
3. If Power BI requests the database location, point it to:
   ```text
   data/db/bluestock_mf.db
   ```
4. Refresh the data if required.
5. Explore the dashboard pages using the available slicers and interactive visuals.

The dashboard covers:

- Industry Overview
- Fund Performance
- Investor Analytics
- SIP & Market Trends

## Limitations

- Analysis covers a defined set of 40 mutual fund schemes.
- Historical results do not guarantee future performance.
- Investor and SIP transaction data covers a limited historical period.
- Benchmark suitability varies across fund categories.
